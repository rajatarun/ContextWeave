# Results

Files in this directory are produced by the scripts in `scripts/experiments/`.
`FINDINGS.md` and `PENDING.md` are generated by
`scripts/experiments/write_results.py`. A cell is `pending` when the artifact
it would have been copied from is missing or the estimate is null.

Do not hand-edit numbers in `FINDINGS.md`. Change the stage output and
re-run the writer.
